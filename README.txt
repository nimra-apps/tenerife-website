Tenerife Café — Restaurant Website
===================================

Open index.html in a browser to preview the site.

Included:
- Full visual menu with all supplied dishes
- Category filters
- Individual local image asset for every dish
- Separate service/ambience image assets
- Responsive design
- Mobile navigation
- Scroll animations
- Phone, Facebook and map actions
- Dedicated images/ folder for easy replacement

IMAGE MANAGEMENT
----------------
All image assets are in:
images/menu/
images/services/

The included SVG assets are editable local visual placeholders. Replace them
with real Tenerife Café photography while keeping the same filenames, or update
the image extension in index.html.
